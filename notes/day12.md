# Day 12 - 리스트 다루기: 필터와 검색

## 배운 것
- 함수에 리스트를 매개변수로 넘겨서 처리할 수 있다.
- return은 반복문이 다 끝난 뒤에 와야 모든 항목을 확인한다.
- 리스트 컴프리헨션: `[넣을 값 for 항목 in 리스트 if 조건]`
- for 뒤의 if는 골라내기, for 앞의 `A if 조건 else B`는 값 바꾸기다.
- 문자열에서 `in`은 글자가 포함되어 있는지 확인한다. (`"공부" in "Python 공부"`)
- `==`는 완전히 같을 때만 True다.
- `결과 = 함수()`로 return 값을 변수에 담아서 쓸 수 있다.
- 리스트가 비었는지 먼저 검사하고 return하면 코드가 깔끔해진다.

## 적용한 기능
- count_all_todos(), count_not_done_todos()로 개수 세기
- get_done_todos(), get_not_done_todos()로 완료/미완료 필터
- search_todos()로 제목 검색
- print_todo_list()로 어떤 목록이든 같은 형식으로 출력
- search_menu()로 검색어 입력과 빈 검색어 처리
- 메뉴에 5·6·7번 추가, 종료를 0번으로 변경

## 헷갈렸던 것
- return을 for 안에 써서 첫 번째 항목만 확인하고 끝나는 실수
- todo(할 일 하나)와 todos(전체 목록) 구분
- 함수 정의의 매개변수 개수와 호출할 때 넘기는 값 개수를 맞춰야 한다

## 알아 둘 점
- 필터·검색 결과의 번호는 걸러진 목록 안의 번호라서 전체 목록 번호와 다르다.
