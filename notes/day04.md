# Day 4: 반복문

## 배운 것
- `for` 반복문
- `range()` 사용법
- 누적 합계
- `while` 반복문
- `continue`

## 핵심
- `range(1, 5)`는 1, 2, 3, 4를 만든다.
- `continue`는 이번 반복의 남은 코드를 건너뛴다.
- `break`는 반복문 전체를 끝낸다.

## 문제 풀이
- 문제 1: 음식 목록을 하나씩 출력
- 문제 2: 1부터 입력한 숫자까지 출력
- 문제 3: 점수 합계 구하기
- 문제 4: 할 일에 번호 붙이기
- 문제 5: `while`로 카운트다운
