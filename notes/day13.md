# Day 13 - 튜플·세트와 클래스 기초

## 배운 것
### 튜플과 세트
- 튜플 `( )`: 순서가 있고 값을 바꿀 수 없다.
- 언패킹: `title, done = ("Python 공부", False)`
- `enumerate()`는 (번호, 값) 튜플을 하나씩 준다.
- 세트 `{ }`: 순서가 없고 중복이 없다. `set(리스트)`로 중복을 제거한다.
- 세트는 `in` 검사가 리스트보다 빠르다.
- 빈 세트는 `set()`, `{}`는 빈 딕셔너리다.
- f-string 안에서는 바깥과 다른 따옴표를 쓰는 게 안전하다.

### 클래스
- 클래스는 설계도, 객체는 설계도로 만든 실제 물건이다.
- 생성자 `__init__`은 객체를 만들 때 자동으로 실행된다. 이름을 정확히 써야 한다.
- `self`는 메서드를 부른 객체 자신이다. `dog1.bark()`는 `Dog.bark(dog1)`과 같다.
- 속성은 `self.이름 = 값`으로 만들고, 밖에서는 `객체.이름`으로 쓴다.
- 생성자에서 매개변수 없이 기본값을 정할 수 있다. (`self.done = False`)
- 객체마다 상태(속성)를 따로 가진다.
- `__str__`은 `print(객체)` 할 때 나올 문자열을 return한다.

## 만든 것
- Student: 이름·전공 저장, introduce()
- Book: 대출 상태 관리, borrow(), return_book(), show()
- Task: 할 일 하나를 클래스로, complete(), __str__()

## 헷갈렸던 것
- f-string 바깥에서 `{변수}`를 쓰면 세트가 만들어져서 조건이 항상 True가 된다.
- f-string의 f는 문자열마다 따로 붙여야 한다.
- 같은 이름의 클래스를 두 번 정의하면 나중 것이 앞의 것을 덮어쓴다.
- 클래스는 정의만 하면 아무것도 출력하지 않는다. 객체를 만들고 메서드를 불러야 한다.
- 코드를 고친 뒤에는 꼭 실행해서 결과를 비교한다.
