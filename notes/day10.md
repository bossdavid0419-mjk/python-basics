# Day 10 - 예외 처리

## 배운 것
- 예외는 프로그램 실행 중 발생하는 오류이다.
- try 안에는 오류가 날 수 있는 코드를 넣는다.
- except 예외이름: 에서 특정 오류를 처리한다.
- FileNotFoundError는 파일이 없을 때 발생한다.
- ValueError는 값의 종류가 맞지 않을 때 발생한다.
- OSError는 파일 입출력 관련 오류를 포괄적으로 처리할 수 있다.
- continue는 현재 반복을 건너뛰고 다음 반복으로 넘어간다.
- return은 현재 함수를 즉시 종료한다.
- break는 반복문을 완전히 종료한다.

## 적용한 기능
- 프로그램 시작 때 todos.txt가 없어도 실행된다.
- 숫자가 아닌 번호 입력을 처리한다.
- 잘못된 메뉴 번호를 처리한다.
- 파일 저장 실패를 처리한다.
- 잘못된 파일 형식의 줄은 건너뛴다.
- 완료 여부 값이 True 또는 False가 아니면 건너뛴다.
