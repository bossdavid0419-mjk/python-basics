# Day 8: 작은 할 일 관리 프로그램

## 학습 목표

- 리스트와 딕셔너리를 함께 사용해 할 일을 저장한다.
- 함수로 기능을 나누어 프로그램을 구성한다.
- `while` 반복문과 메뉴 선택으로 프로그램을 계속 실행한다.
- 입력값과 번호의 유효성을 검사한다.
- `strip()`으로 입력값 앞뒤 공백을 제거한다.
- `pop()`으로 리스트에서 항목을 삭제한다.

## 새로 배운 내용

### `strip()`

`strip()`은 문자열 양끝의 공백을 제거한다.  
가운데에 있는 공백은 그대로 유지된다.

```python
title = input("할 일을 입력하세요: ").strip()
```

예를 들어 `"  Python 공부  "`를 `strip()`하면 `"Python 공부"`가 된다.

빈 입력이나 공백만 입력한 경우를 막기 위해 다음처럼 사용했다.

```python
if title == "":
    print("할 일 내용을 입력해 주세요.")
    return
```

### `pop()`

`pop()`은 리스트에서 특정 위치의 항목을 삭제하고, 삭제된 항목을 반환한다.

```python
removed = todos.pop(number - 1)
```

사용자는 번호를 1부터 입력하지만, 파이썬 리스트는 0부터 시작하기 때문에 `number - 1`을 사용했다.

## 할 일 데이터 구조

각 할 일은 딕셔너리로 저장했다.

```python
todo = {
    "title": title,
    "done": False
}
```

- `title`: 할 일 내용
- `done`: 완료 여부, 처음에는 `False`

모든 할 일은 `todos` 리스트에 저장했다.

## 만든 기능

### 할 일 보기

`show_todos()` 함수는 전체 할 일 개수와 목록을 출력한다.

```python
print(f"전체 할 일: {len(todos)}개")
```

할 일이 없으면 `할 일이 없습니다.`를 출력하고 함수를 종료한다.

### 할 일 추가

`add_todo()` 함수는 입력값의 앞뒤 공백을 제거하고, 빈 값이면 추가하지 않는다.

정상적인 입력이면 딕셔너리를 만들어 `todos`에 추가한다.

### 완료 처리

`complete_todo()` 함수는 선택한 번호가 이미 완료된 할 일인지 확인한다.

이미 완료된 경우에는 상태를 바꾸지 않고 다음 메시지를 출력한다.

```text
이미 완료된 할 일입니다.
```

### 할 일 삭제

`delete_todo()` 함수는 선택한 번호의 할 일을 삭제한다.

삭제 전에 번호가 올바른지 검사하고, 삭제된 할 일의 제목을 출력한다.

```python
removed = todos.pop(number - 1)
print(f"'{removed['title']}' 할 일이 삭제되었습니다.")
```

## 메뉴 구조

```text
1. 할 일 보기
2. 할 일 추가
3. 할 일 완료 처리
4. 할 일 삭제
5. 종료
```

`while True`로 프로그램을 반복 실행하고, `5`를 선택하면 `break`로 종료한다.

## 배운 점

- 함수 하나에는 한 가지 기능을 넣으면 코드가 더 읽기 쉬워진다.
- 사용자 입력은 항상 검사해야 한다.
- 번호 입력은 1부터 시작하지만 리스트 인덱스는 0부터 시작한다.
- 이미 완료된 할 일을 다시 처리하지 않도록 조건을 넣었다.
- 삭제 기능을 추가하면서 메뉴 번호와 함수 실행을 올바르게 연결했다.
